# AI嘘発見ゲーム

容疑者役のAIに質問して証言の矛盾を見つけ、嘘をついている人物を当てる推理ゲームです。
画面は Gradio、AIは OpenAI API を使います。

## 特徴
- **3つの固定事件**：難易度（やさしい／ふつう／むずかしい）ごとに、内容の決まった事件が1つずつあります。
- **難易度で変わるもの**：嘘の複雑さ、証拠の開示、質問できる回数、ヒントの回数、スコア。
- **推理小説のロジック**：アリバイ、証言と記録の矛盾、補強の嘘、秘密の暴露、無実の人の隠し事。
- **ニックネーム＋ランキング**：スコアをニックネームごとに記録して、ランキングに表示します。

| 難易度 | 事件 | 容疑者 | 質問回数 | 証拠 | 嘘の特徴 |
|---|---|---|---|---|---|
| やさしい | 美術館の絵画盗難事件 | 3人 | 15 | 最初から全部見える | 嘘は1つ。証拠を突きつけると認める |
| ふつう | 社内の試作USB紛失事件 | 3人 | 12 | 質問で段階的に見つかる | 補強の嘘あり。うっかり本音が漏れる |
| むずかしい | 雪の山荘・指輪消失事件 | 4人 | 14 | 質問で段階的に見つかる | 嘘が連鎖。無実の人も秘密を隠す |

## 環境構築（初回のみ）

### 1. uv をインストール
- macOS / Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`

### 2. リポジトリを取得して依存関係を入れる
```bash
git clone <このリポジトリのURL>
cd ai-liar-game
uv sync
```
`uv sync` で Python の仮想環境（`.venv`）と必要なパッケージが自動で用意されます。
（省略しても、次の `uv run` が自動で同じことをします。）

### 3. APIキーを設定
```bash
cp .env.example .env     # Windows: copy .env.example .env
```
`.env` を開き、`OPENAI_API_KEY=` に **自分の** APIキーを記入します。
使うモデルを変えたいときは、`OPENAI_MODEL=モデル名` の行も追加します（行頭に `#` を付けない）。
`.env` は Git に載らないので、キーが公開されることはありません（絶対に `.env.example` にキーを書かないでください）。

## 起動
```bash
uv run liar-game
```
ブラウザが自動で開きます（開かないときは http://127.0.0.1:7860 を手動で開いてください）。
終了するときは、ターミナルで `Ctrl + C` を押します。

## テスト
```bash
uv run pytest
```
APIを呼ばずに動くので、キーがなくても実行できます。
