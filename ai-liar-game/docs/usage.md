# 使い方

## 遊び方
1. 「事件を解く」タブで、ニックネーム（12文字まで）と難易度を選び、「事件を開始」を押します。
2. 容疑者をプルダウンで選び、自由に質問します。**質問できる回数には上限**があります（残り回数は画面に表示）。
3. 気になることを具体的に質問すると、**新しい証拠が見つかる**ことがあります（見つかると通知が出ます）。
4. 詰まったら「助手ミナトにヒントを聞く」。答えは教えてくれませんが、回数制限と減点があります。
5. 嘘をついている人物が分かったら、右側で選んで「推理を確定する」を押します。**確定は1回だけ**です。
6. 「ランキング」タブで、総合・難易度別の順位が見られます。

「事件を開始 / やり直す」を押すと、同じ難易度（または別の難易度）を最初からやり直せます。

## スコア
- 正解：`基本点 ＋ 残り質問数 × ボーナス − ヒント回数 × 減点`（0点未満にはなりません）
- 不正解：0点

| 難易度 | 基本点 | 質問ボーナス | ヒント減点 | ヒント回数 |
|---|---|---|---|---|
| やさしい | 100 | 5 | 10 | 3 |
| ふつう | 200 | 10 | 30 | 2 |
| むずかしい | 300 | 10 | 60 | 1 |

数値は `src/liar_game/difficulty.py` で変更できます。

## ランキング
- 記録は `data/ranking.json` に保存されます（Git には載りません）。保存先は環境変数 `LIAR_RANKING_PATH` で変更できます。
- 同じニックネームは、**ベストスコア**だけが載ります。「総合」は、各難易度のベストスコアの合計です。
- ニックネームは入力するだけで、ログインや重複チェックはありません。同じ名前を使えば、同じ人として集計されます。

### チーム全員で1つのランキングを共有したいとき
ランキングは、**ゲームを起動しているパソコンに保存**されます。全員が自分のパソコンで起動すると、ランキングは別々になります。共有したい場合は、1台のパソコンで起動して、他の人はそのURLにアクセスします。

1. 起動する人が、同じネットワークに公開する設定で起動します。
   - Windows (PowerShell)：`$env:GRADIO_SERVER_NAME="0.0.0.0"; uv run liar-game`
   - macOS / Linux：`GRADIO_SERVER_NAME=0.0.0.0 uv run liar-game`
2. 他の人は、ブラウザで `http://<起動した人のIPアドレス>:7860` を開きます。
3. 注意：質問のたびに、**起動した人のAPIキーの料金**がかかります。同じネットワーク内の人だけに共有してください。ファイアウォールの確認ダイアログが出たら、プライベートネットワークのみ許可します。

## 事件データ
事件は `src/liar_game/cases.py` に**固定データ**として定義されています（難易度ごとに1つ）。ゲーム中や再起動で内容が変わることはありません。

事件を編集したいときは、次のルールを守ってください（`uv run pytest` で整合性がチェックされます）。
- 嘘つき（`is_liar: True`）は必ず1人。
- 嘘つきには、嘘を崩せる証拠（`contradicted_by`）が必要。
- 最初から見える証拠（`unlock: {"type": "start"}`）が1つ以上必要。
- 証拠の開示回数（`count`）は、その難易度の質問上限以内にする（詰み防止）。

### 事件を構成する要素
| 項目 | 意味 |
|---|---|
| `truth` | その人が知っている本当の行動 |
| `lie` / `cover_lies` | 嘘つきの主な嘘 / 嘘を補強する二次的な嘘 |
| `secrets` | 無実の人が隠したがっている事情（嘘ではなく「言いたくない」） |
| `slip` | 嘘つきがうっかり口にする、犯人しか知り得ない情報（秘密の暴露） |
| `evidence.unlock` | 証拠が見つかる条件（最初から／質問N回／キーワードに触れる） |
| `hints` / `solution` | ヒントの文面 / 解説 |

## モデルの変更
`.env` に `OPENAI_MODEL=モデル名` と書きます（行頭に `#` を付けないでください。省略時は `gpt-4o-mini`）。
モデル名が間違っていると、質問したときにエラーが出ます。

## AIの回答について
容疑者の返答は、AIが設定をもとに生成します。設定を守るよう指示していますが、モデルによっては、うっかり設定を外れた返答をすることがあります（特に、ふつう・むずかしいの「うっかり口にする」場面は確実ではありません）。そのときは、質問を変えてみてください。
